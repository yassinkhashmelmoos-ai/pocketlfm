# ⚡ Thunder AGI — الرَّعد للذكاء العام المصطنع

**The most advanced on-device AI assistant for Android.**

Created by **Yassin Khashmelmoos**

## Features

- 🧠 Hybrid recurrent + attention architecture, runs 100% offline
- 🎨 **ThunderImagen** — On-device image generation (Gemini-quality config)
- 🔍 **Web-augmented AI** — Wikipedia, weather, dictionary, currency, DuckDuckGo
- 💬 **Persistent sessions** — Full conversation history, never loses context
- 🎤 **Voice input** — Speak in Arabic or English
- 📁 **File export** — Save responses as TXT, Markdown, HTML, JSON
- 🤝 **P2P sync** — Share fine-tune data between nearby devices via WiFi Direct
- 🧬 **Self-improvement** — Learns from feedback, evolves its own system prompt
- ⚡ **Scheme scripting** — Built-in Scheme interpreter for self-modification
- 📊 **Knowledge graph** — Learns facts from every conversation
